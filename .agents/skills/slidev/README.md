# Guomics Slidev Skill

This local skill documents how to work with the Guomics group meeting Slidev template in this repository.

It covers:

- the PPT-derived visual language
- available layouts and their slots
- reusable Vue components
- public resource paths for backgrounds, logos, and figures
- the workflow for using this repository as a new group meeting deck

The main instructions live in `SKILL.md`.
